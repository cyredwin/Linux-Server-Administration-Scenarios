# 🐧 Linux Server Administrator — Task Scenarios

This repository contains **hands-on Linux Server Administration scenarios and exercises** designed to practice real-world tasks commonly performed by Linux system administrators.

The goal of this repository is to build practical Linux administration skills by working through different scenarios involving users, permissions, networking, storage, services, security, troubleshooting, automation, and system maintenance.

The scenarios are designed to simulate tasks that a **Linux Server Administrator / System Administrator** may encounter in a production environment.

---

## 🎯 Objectives

By completing the scenarios in this repository, I aim to improve my ability to:

* Administer Linux servers from the command line
* Configure and troubleshoot Linux systems
* Manage users and groups
* Configure user profiles and environments
* Manage files and directories
* Configure permissions and ownership

# 🛠️ Linux Server Administration Scenarios

Each section of this repository focuses on a specific Linux administration responsibility.

The scenarios are based on tasks that could be assigned to a Linux administrator in a real working environment.

## 01 — Configure User Profiles

### Scenario

A new developer has joined the organization.

The developer requires a Linux account with a properly configured shell environment.

As the Linux Server Administrator, you are responsible for configuring the user's profile.

### Tasks

Practice tasks such as:

* Create a Linux user
* Configure the user's home directory
* Configure `.bashrc`
* Add environment variables
* Configure aliases
* Modify the `PATH`
* Apply profile changes
* Verify the user's environment

### Commands

```bash
useradd
passwd
vim
source
ls -ld
chown
su
```
